# SmartKada

An AI Web-Based Smart Study Planner for Students

# Overview

SmartKada is a web-based study planner that uses AI to help students organize their schedules,track assignments, and improve study habits. It generates personalized study plans, sends reminders, and provides AI-driven feedback using the Gemini AI API.

# Setup Instructions

Make sure you have Node.js installed in your device

1. Clone the project (Recommend Github Desktop)
2. Open project in VS code
3. Run this command in terminal => npm install
4. Run this command in terminal => npm run dev
